# Deviations

Append-only. One file per departure from the registered design.

Each entry records what changed, the date, the reason, and — the part that matters —
whether it was decided before or after the affected result was visible. A deviation logged
before sight of the result and a deviation logged after are different kinds of thing, and
collapsing them is the failure this directory exists to prevent.

After the freeze, corrections live here. The frozen text is never edited.
